# Asesoría Leyva · V4
Demo estática sin dependencias. Publicar el contenido de esta carpeta en la raíz de un repositorio GitHub Pages (main / root).

- 11 páginas, rutas relativas, recursos en assets/.
- Ilustraciones SVG originales: claridad, crecimiento y renta. Sustituibles en assets/img/.
- Tarifas: campaña de renta desde 29 € como propuesta pendiente de aprobación; resto bajo presupuesto.
- Formulario de simulación sin transmisión ni almacenamiento de datos.
- Branding independiente: branding/index.html.
- Antes de producción: aprobar textos, precios, impuestos aplicables y completar/revisar páginas legales.
- Verificación: enlaces locales y sintaxis JS correctos; Chromium bloquea navegación local en el entorno, por lo que quedan pendientes pruebas visuales y de interacción reales.
